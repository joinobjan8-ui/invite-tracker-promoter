# PROMOTER Invite Tracking Bot (Render Free)

Telegram bot for the PROMOTER group: gives every user a personal invite link, counts unique new members who join through it, and shows `/topinviter` (up to 100). MongoDB Atlas keeps the data across Render restarts.

## How users use it
- **In the group:** tap **🔗 Get My Invite Link** (under the welcome message / `/topinviter`) or send `/mylink`. The bot posts the link *in the group* with a **📋 Copy My Link** button; tapping the link text itself also copies it. No private chat / START needed.
- The link message (and the user's command) is auto-deleted after `AUTO_DELETE_SECONDS` to keep the group clean.
- Several people joining within a couple of seconds get **one** combined welcome message.

## Limitations
- Only joins through a link generated by this bot are attributed; history cannot be reconstructed.
- Counts are unique Telegram accounts, not proof of real people - admins should review winners.
- The bot does not distribute prizes.

## Setup
1. **Bot:** create it with `@BotFather`, copy the token.
2. **MongoDB Atlas:** create a user + database, allow Render in Network Access, copy the connection string.
3. **Render:** New Web Service from your GitHub repo (render.yaml is included). Environment variables:
   - `BOT_TOKEN`, `MONGODB_URI` (required)
   - `GROUP_ID` = `@Promoter0007` or the numeric chat id (numeric is more reliable)
   - `DB_NAME` = `promoter_giveaway`
   - `WEBHOOK_SECRET` = any random string (Render can generate it)
4. **Admin:** make the bot an admin of the group with *Invite users via link* (needed for `chat_member` updates and link creation) and, optionally, *Delete messages* (for auto-delete).
5. **Webhook:** registered **automatically** on every start (needs `RENDER_EXTERNAL_URL`, which Render sets itself). You can still open `/setup-webhook?key=YOUR_WEBHOOK_SECRET` manually.

> After updating from an older version, just redeploy - the webhook is re-registered with the new `callback_query` update type automatically.

## Optional environment variables
| Variable | Default | Meaning |
|---|---|---|
| `AUTO_DELETE_SECONDS` | 120 | Delete link/leaderboard messages in the group after N seconds (0 = keep) |
| `LINK_COOLDOWN_SECONDS` | 10 | Min. seconds between link requests per user in the group |
| `WELCOME_BATCH_SECONDS` | 2 | Window for combining welcome messages |
| `KEEPALIVE_SECONDS` | 540 | Self-ping interval to keep the free instance and MongoDB warm |
| `AUTO_SET_WEBHOOK` | 1 | Set `0` to disable automatic webhook registration |

## Keeping the free Render instance awake
Render Free sleeps after ~15 min without traffic, and the first message after that is slow. The bot pings itself every `KEEPALIVE_SECONDS`, but for best reliability also add a free monitor (UptimeRobot / cron-job.org) that opens `https://YOUR-SERVICE.onrender.com/health` every 5 minutes.

## Commands
- `/start` - help
- `/mylink` - your personal invite link (works in the group and in private chat)
- `/topinviter` - leaderboard
