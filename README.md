# PROMOTER Invite Tracking Bot (Render Free)

A Telegram bot for the PROMOTER group that creates a unique invite link for each user, counts unique new members who join using that link, and displays `/topinviter` (up to 100 entries). MongoDB Atlas stores the data so it survives Render restarts/redeploys.

## Important limitations
- Only joins that happen through a link generated by this bot can be attributed.
- Existing members and their historical invitations cannot be reconstructed retroactively.
- Telegram does not reliably expose who invited a person when they join through a normal group link or another admin's link.
- This tracks unique referred Telegram accounts, not whether they are real people; set giveaway rules to deter fake accounts.
- Do not promise that referral totals prove giveaway eligibility. Admins should review entries before paying prizes.

## 1. Create the Telegram bot
1. Open `@BotFather` in Telegram.
2. Send `/newbot`, follow the steps, and copy the bot token.
3. Keep the token private. If it leaks, regenerate it in BotFather.

## 2. Configure MongoDB Atlas
1. Create a database user and database in Atlas.
2. Add network access that permits your Render service to connect. For testing, Atlas `0.0.0.0/0` allows all IPs, so use a strong database password and least-privilege user; prefer a tighter allowlist if your setup supports stable outbound IPs.
3. Copy the MongoDB connection string and replace the password placeholder. Do not post it publicly.

## 3. Deploy to Render
1. Upload this project to a GitHub repository.
2. In Render, create a **New Web Service** and connect that repository.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn main:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120`
5. Add environment variables:
   - `BOT_TOKEN` = token from BotFather
   - `GROUP_ID` = `@Promoter0007` or the group's numeric chat ID (numeric ID is more reliable)
   - `MONGODB_URI` = Atlas connection string
   - `DB_NAME` = `promoter_giveaway`
   - `WEBHOOK_SECRET` = random secret containing only letters, numbers, `_` or `-`
   - `RENDER_EXTERNAL_URL` = your Render service URL, e.g. `https://promoter-invite-tracker.onrender.com` (Render often supplies this automatically; set it manually if missing)
6. Deploy and wait until the service is live.

## 4. Make the bot an admin
Add the bot to the PROMOTER group and grant it permission to **invite users / manage invite links**. It must be an administrator so Telegram sends `chat_member` updates. Do not give it unrelated permissions.

## 5. Set up the webhook
Open this URL in a browser, replacing the domain and secret:

`https://YOUR-SERVICE.onrender.com/setup-webhook?key=YOUR_WEBHOOK_SECRET`

The response should contain `"ok": true`. Keep the setup URL secret; don't share it.

## 6. Test it
1. Open the bot's private chat and press **Start**.
2. Send `/mylink` to get your personal invite link.
3. Have a test account that is not already in the group join using that link.
4. In the group, send `/topinviter`.

Commands:
- `/start` — help
- `/mylink` — private chat only; creates or returns a new personal invite link
- `/topinviter` — group leaderboard (up to 100 inviters)

## Giveaway prize pool note
The bot counts referral totals; it does not automatically distribute TON or verify payments. Publish the winner selection date, valid-invite rules, anti-spam policy, and prize distribution before the contest starts.
